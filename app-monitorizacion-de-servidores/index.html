App Monitorización de servidores

El objetivo de esta práctica es desarrollar una aplicación web completa capaz de gestionar y monitorizar máquinas virtuales en un entorno local (EducaMaX/Ubuntu) mediante una interfaz gráfica remota alojada en la nube (GitHub Pages).

 

En primer lugar he creado un script de automatización en Bash ( preparacion.sh ) que interactúa con el hipervisor VirtualBox. Este script verifica la instalación del software necesario y crea automáticamente tres máquinas virtuales de prueba (Server1, Server2 , Server3 ) con configuraciones de hardware específicas (RAM reducida y sin disco duro para pruebas ligeras).

Esto garantiza que el entorno de despliegue sea consistente y reproducible.

 

En segundo lugar se ha programado un script híbrido en Bash y Python 3 (backend.sh) que levanta un servidor HTTP local en el puerto 8000. Este servidor actúa como una API Middleware que:

    1. Escucha peticiones web (GET requests).

    2. Ejecuta comandos de sistema en el host para encender, apagar o consultar el estado de las máquinas.

    3. Devuelve la información en formato JSON.

    4. Gestiona las cabeceras CORS (Cross-Origin Resource Sharing) para permitir conexiones seguras desde dominios externos.

Dado que JavaScript (Frontend) no tiene permisos de seguridad para ejecutar comandos del sistema operativo directamente, este backend actúa como el "cerebro" o puente necesario. Permite la comunicación segura y controlada entre la interfaz web y el núcleo del sistema operativo del servidor.

    # --- FUNCIÓN: OBTENER ESTADÍSTICAS DEL PC REAL (HOST) ---
    def get_host_stats(self):
        # 1. RAM: Ejecuta 'free -m' en Linux para ver la memoria libre
        try:
            mem_output = subprocess.check_output(['free', '-m'], text=True).splitlines()[1].split()
            total_ram = int(mem_output[1])
            used_ram = int(mem_output[2])
            ram_percent = round((used_ram / total_ram) * 100, 1)
        except:
            ram_percent = 0

        # 2. CPU: Usa la librería OS para ver la carga de trabajo del sistema
        try:
            load = os.getloadavg()[0] # Carga del último minuto
            cpu_count = os.cpu_count() or 1
            # Calculamos porcentaje basado en núcleos
            cpu_percent = min(round((load / cpu_count) * 100, 1), 100) 
        except:
            cpu_percent = 0
            
        return {'cpu': cpu_percent, 'ram': ram_percent}

    # --- FUNCIÓN: OBTENER DETALLES TÉCNICOS DE LA VM ---
    def get_vm_extended_info(self, vm_name):
        # Ejecuta 'VBoxManage showvminfo' para sacar MAC, Tipo de SO, VRAM, etc.
        try:
            info = subprocess.check_output(['VBoxManage', 'showvminfo', vm_name, '--machinereadable'], text=True)
            data = {'ram': '?', 'cpus': '1', 'vram': '?', 'os': '?', 'mac': '?', 'vrde': 'OFF'}
            
            # Parseamos línea a línea buscando las claves que nos interesan
            for line in info.splitlines():
                if '=' in line:
                    key, val = line.split('=', 1)
                    val = val.strip('\"')
                    
                    if key == 'memory': data['ram'] = val
                    elif key == 'cpus': data['cpus'] = val
                    elif key == 'vram': data['vram'] = val
                    elif key == 'ostype': data['os'] = val
                    elif key == 'macaddress1': data['mac'] = val
                    elif key == 'vrde': data['vrde'] = val
                    
            return data
        except:
            return {}

        vm_name = params.get('name', [''])[0]
        response = {}

        try:
            # --- CASO 1: ESTADO GENERAL (LOOP) ---
            if command == 'status':
                # Pregunta a VirtualBox qué máquinas existen
                result = subprocess.check_output(['VBoxManage', 'list', 'vms'], text=True)
                vms = []
                for line in result.splitlines():

                    if len(parts) > 1:

                        # Miramos si está 'running', 'paused' o 'stopped'

                        state = 'stopped'

                        elif 'VMState=\"paused\"' in info_dump: state = 'paused'

                            'specs': details
                        })
                
                # Devolvemos JSON con VMs + Salud del Host

            elif command == 'stop' and vm_name:

            elif command == 'acpi' and vm_name:

                subprocess.run(['VBoxManage', 'controlvm', vm_name, 'acpipowerbutton'], check=True)
                response = {'status': 'ok', 'msg': 'ACPI SHUTDOWN SIGNAL SENT'}

            elif command == 'reset' and vm_name:
                subprocess.run(['VBoxManage', 'controlvm', vm_name, 'reset'], check=True)
                response = {'status': 'ok', 'msg': 'SYSTEM HARD RESET'}

            elif command == 'pause' and vm_name:
                # Congela la CPU de la VM
                subprocess.run(['VBoxManage', 'controlvm', vm_name, 'pause'], check=True)
                response = {'status': 'ok', 'msg': 'PROCESS FROZEN'}

            elif command == 'resume' and vm_name:
                # Descongela la CPU
                subprocess.run(['VBoxManage', 'controlvm', vm_name, 'resume'], check=True)
                response = {'status': 'ok', 'msg': 'PROCESS RESUMED'}

            # --- CASO 3: GESTIÓN DE TIEMPO (SNAPSHOTS) ---
            elif command == 'snapshot' and vm_name:
                # Borramos snapshot anterior para ahorrar espacio y creamos uno nuevo
                subprocess.run(['VBoxManage', 'snapshot', vm_name, 'delete', SNAPSHOT_NAME], stderr=subprocess.DEVNULL)
                time.sleep(0.5)
                subprocess.run(['VBoxManage', 'snapshot', vm_name, 'take', SNAPSHOT_NAME], check=True)
                response = {'status': 'ok', 'msg': 'SYSTEM STATE SAVED'}

            elif command == 'restore' and vm_name:
                # Restaurar requiere apagar la máquina primero
                subprocess.run(['VBoxManage', 'controlvm', vm_name, 'poweroff'], stderr=subprocess.DEVNULL)
                time.sleep(1)
                subprocess.run(['VBoxManage', 'snapshot', vm_name, 'restore', SNAPSHOT_NAME], check=True)
                response = {'status': 'ok', 'msg': 'TIMELINE RESTORED'}

            # --- CASO 4: ESPIONAJE (SCREENSHOT) ---
            elif command == 'screenshot' and vm_name:
                tmp_file = f'/tmp/{vm_name}_spy.png'

            else:
                response = {'status': 'error', 'msg': 'INVALID COMMAND SYNTAX'}

        except Exception as e:
            print(f'[ERROR] {e}')
            response = {'status': 'error', 'msg': str(e)}

        self.wfile.write(json.dumps(response).encode('utf-8'))
    
    # Maneja las peticiones 'OPTIONS' que hacen los navegadores modernos antes de conectar
    def do_OPTIONS(self):

        self.send_header('Access-Control-Allow-Origin', '*')
        self.send_header('Access-Control-Allow-Methods', 'GET, OPTIONS')
        self.send_header('Access-Control-Allow-Headers', 'X-Requested-With')
        self.end_headers()

# Arrancar el loop infinito del servidor
with socketserver.TCPServer(('', PORT), RequestHandler) as httpd:

Por ultimo se diseña una interfaz gráfica moderna utilizando HTML5, CSS3 y JavaScript (index.html), alojada en GitHub Pages. La aplicación incluye:

    1. Dashboard Dinámico: Detecta automáticamente cuántas máquinas existen y genera tarjetas de control para cada una.

    2. Estadísticas en Tiempo Real: Muestra contadores de servidores activos/inactivos y hora de última actualización.

    3. Comunicación Asíncrona: Utiliza fetch() para consultar al backend cada 5 segundos sin recargar la página, actualizando los indicadores de estado (verde/rojo) en vivo.

Esto proporciona una capa de abstracción visual (GUI) para el usuario final, permitiendo la administración remota de la infraestructura.

                    // El backend nos manda la imagen en texto Base64, aquí la ponemos en el <img>
                    document.getElementById('spy-img').src = "data:image/png;base64," + data.image;
                    document.getElementById('spy-modal').style.display = 'flex'; // Mostrar modal
                } else {
                    alert("CAPTURE FAILED: " + data.msg);
                }
            } catch(e) { log("SPY_MODULE ERROR"); }
            
            btn.innerText = "👁️ CAPTURE SCREEN";
        }

        function closeSpy() {
            document.getElementById('spy-modal').style.display = 'none';
        }

        // Función para escribir en la consola negra de abajo
        function log(msg, color) {
            const c = document.getElementById('console');
            const ts = new Date().toLocaleTimeString();
            c.innerHTML += `<div class="log-entry" style="color:${color || 'inherit'}"><span class="log-ts">[${ts}]</span> ${msg}</div>`;
            c.scrollTop = c.scrollHeight; // Auto scroll hacia abajo
        }

        // Iniciar el bucle eterno
        setInterval(loop, 3000);
        loop();
    </script>

Durante el desarrollo se solucionaron dos desafíos clave:

  1. Seguridad del Navegador: Se configuró el navegador para permitir peticiones desde un origen seguro (HTTPS/GitHub) a un recurso local (HTTP/Localhost).

  2. Escalabilidad: El sistema fue programado para ser agnóstico; no requiere saber los nombres de los servidores de antemano, sino que se adapta dinámicamente a las máquinas virtuales que existan en el equipo anfitrión .
