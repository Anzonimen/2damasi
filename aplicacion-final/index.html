En primer lugar realice un prompt basico para crear una app estandar:

Actúa como un Ingeniero de Software Principal y Arquitecto de Soluciones experto en desarrollo Full Stack. Tu objetivo es diseñar y desarrollar una aplicación web progresiva (PWA) de nivel empresarial, escalable y segura.

**Contexto del Proyecto:**
Necesito construir una aplicación "Multi-Todo" robusta que combine capacidades offline-first con sincronización en la nube. La aplicación debe ser agnóstica al dispositivo (responsive extremo) y manejar tipos de datos complejos.

**Stack Tecnológico Preferido:**
* **Frontend:** React (Vite) + TypeScript.
* **Estilos:** Tailwind CSS (para el manejo de resoluciones y UI adaptable).
* **Estado & Lógica Local:** TanStack Query + Zustand + Dexie.js (para IndexedDB) / LocalStorage.
* **Backend as a Service:** Supabase (preferido) o Firebase.
* **Internacionalización:** i18next.

**Requisitos Funcionales Estrictos:**

1.  **Arquitectura y Navegación:**
    * Sistema de enrutamiento robusto (React Router) para múltiples pantallas.
    * Diseño Atómico o arquitectura basada en "Features" para organizar los componentes.
    * Interfaz adaptativa: Debe cambiar radicalmente el layout entre Móvil (barra inferior, menús hamburguesa) y Desktop (sidebar, grid layouts).

2.  **Gestión de Datos Híbrida (Offline/Online):**
    * **Local:** Almacenamiento de configuraciones en JSON local/LocalStorage y datos pesados en IndexedDB.
    * **Nube (CRUD):** Implementación completa de Crear, Leer, Actualizar y Borrar entidades en la base de datos.
    * **Sincronización:** Lógica para sincronizar cambios locales cuando se recupere la conexión.

3.  **Gestión de Archivos (Storage):**
    * Capacidad para subir, previsualizar y eliminar imágenes, PDFs y audios.
    * Uso de Buckets de almacenamiento (Supabase Storage/Firebase Storage).

4.  **Seguridad y Usuarios:**
    * Autenticación robusta (Email/Password + Social Auth si aplica).
    * Row Level Security (RLS) o Reglas de seguridad: Un usuario solo puede editar/borrar sus propios datos.
    * Gestión de sesión persistente.

5.  **Extras:**
    * **Conexión API:** Una capa de servicio genérica para consumir APIs externas RESTful.
    * **Multiidioma:** Sistema base para Español/Inglés con archivos JSON separados.
